# 作業コンテキスト（高山裕貴）

スマホ・PCどちらからでも、ここを開けば同じ前提で話が始まります。

- **全体の地図** → [CLAUDE.md](CLAUDE.md)（セッション開始時に自動で読まれます）
- **アドネス株式会社** → [contexts/addness.md](contexts/addness.md)
- **（有）髙山建設** → [contexts/takayama-kensetsu.md](contexts/takayama-kensetsu.md)

## 最初のひと声（これだけ覚えておけば動きます）

| 言うこと | 起きること |
| --- | --- |
| 「今日なにやる？」 | アドネスの今日のToDoと通知を読んで、やることを出す |
| 「高山建設の話」 | 組織を切り替えて、高山建設の今日のToDoと期限を見る |
| 「〇〇さんから返信ある？」 | 通知・コメント・チャットを見て、最後のやり取りと「どちらのボールか」を返す |

## 原則

進捗・数字・決定は **Addness が正本**。このリポジトリは地図です。
食い違ったら Addness が正しいので、このリポジトリを直します。
