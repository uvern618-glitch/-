# 毎朝の段取り

毎朝、今日のToDoを読んで、日誌（`days/YYYY-MM-DD.md`）に「今日の段取り」の節を1つ書く自動化です。
高山さんが朝いちばんに日誌を開くと、今日やることと「最初の一手」が並んでいる状態にするためのものです。

このフォルダは**地図**です。動いているか・何が決まったかはAddnessのゴール
「8. 決まった時刻の自動化を1本作る」`f54fdc50-ebc3-4565-ac1c-08e1a48b2582` にあります。

## 何を・いつ・どこで

| | |
| --- | --- |
| 何を | 今日のToDo（`list_todays_goals`）と各ゴールの理想・本文を読み、`days/YYYY-MM-DD.md` に `## 今日の段取り` を足して push する |
| いつ | 毎日 **7:23 JST**（`CRON_TZ=Asia/Tokyo 23 7 * * *`） |
| どこで | **クラウド**（claude.ai の定期タスク）。PCが閉じていても動き、スマホから日誌を読める |
| 手順 | 同じフォルダの `PROMPT.md`（自動化が毎朝読む唯一の正本） |
| いま動いているか | **まだ動いていません。** 下の「作り方」が済んでいないためです |

**7:30ではなく7:23なのはなぜか。** 定期実行は多くが毎時00分・30分に集まるので、その時刻は混んで遅れます。
数分ずらすと、混まない時間に動きます。

**なぜクラウドなのか。** PCのアプリで動かす自動化は、パソコンとアプリが開いている時間しか動きません。
記憶と日誌の正本をこのリポジトリに置いたので、クラウドからでも日誌に書けます。

## 作り方（高山さんの操作。ここが済むと動きます）

**AIからは作れないことが分かっています。** 2026-10-21に実際に作って1回動かして確かめました。
AIが作れる定期タスクには、次の2つを付けられません（付けられないと何もできません）。

1. **このリポジトリ** — 付かないと、コンテナに `/home/user/-` が存在せず、`PROMPT.md` も `days/` も無い
2. **AddnessのMCP接続** — 付かないと `mcp__Addness__*` のツールが1つも無く、今日のToDoが読めない

どちらも claude.ai の画面からなら付けられます。手順：

1. claude.ai の **定期タスク**（Routines）で新しいタスクを作る
2. **リポジトリ**に `uvern618-glitch/-` を選ぶ
3. **コネクタ**に **Addness** を付ける
4. 時刻を **毎日 7:23（Asia/Tokyo）** にする
5. 指示文に、次の1行を入れる（手順の中身は `PROMPT.md` にあるので、指示文は短くてよい）

```
リポジトリの automations/毎朝の段取り/PROMPT.md を読んで、その手順どおりに今日の段取りを書いてください。
PROMPT.md が見つからない場合は、何も書かずに「手順ファイルが見つからなかった」とだけ報告して終わってください。
```

6. 一度「今すぐ実行」して、`days/`（JSTの今日の日付）に `## 今日の段取り` が書かれ、master に push されていることを確かめる

作ったら、**定期タスクのIDをこの表の「いま動いているか」の行に書き換える**（AddnessのゴールにもIDを残す）。

## 止め方・変え方

- **止める**：claude.ai の定期タスクの一覧で「毎朝の段取り」をオフにする
- **時刻を変える**：同じところで時刻を変える（`PROMPT.md` ではなく定期タスク側の設定）
- **書く中身を変える**：`PROMPT.md` を直す（次の朝から効く）
- **消す**：定期タスクを削除する。このフォルダは消さなくてよい（何をやっていたかの記録になる）

## 無人で動くので、固く守っていること

ゴールを変えない・コメントを書かない・組織の外へ送らない・`days/` 以外のファイルを変えない。
読めなかったことは埋めず「分からなかった」と書く。迷ったら書かずに止まる。

無人の実行は、間違えても誰も止められません。だから「書くだけ」に絞ってあります。
