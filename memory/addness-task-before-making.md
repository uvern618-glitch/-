# 作る前にAddnessのタスクにする

成果物（書類・シート・ファイル）を作り始める前に、Addnessにゴール（タスク）を起票してから作る。作り終えてから起票しない。

**Why:** 2026-10-30、SECOMカード管理シートを先に作ってから後でゴールを作ったところ、「アドネスのタスクにしてから作成してねー」と直された。先に起票しておかないと、作業中の現在地がAddnessに出ず、後から見て何をやっていたか分からなくなる。

**How to apply:** 依頼を受けたら、①該当ゴールを search_goals で探す → ②無ければ起票（親が完了済みなら、生きている親の下に置く）→ ③作る作業を子ゴールにする → ④作る → ⑤所在を本文に書いて完了、の順で進める。ファイルを作るのは②と③の後。
